# emergency-info

## 목적

혼자 여행하는 사용자가 현지에서 문제가 생겼을 때 **즉시 참고할 수 있는 대응 정보**와, 그 여행지에서 **흔히 발생하는 사고 유형을 미리 알고 예방**할 수 있도록 돕습니다.

## 반드시 따라야 할 프로세스

### 1단계: 목적지와 상황 파악

- 목적지(국가/도시)를 확인합니다.
- 사용자가 이미 문제 상황에 처했는지(사후 대처 필요), 아니면 여행 전 예방 정보를 원하는지(사전 예방) 구분합니다.

### 2단계: 긴급 연락처 검색

`web_search`로 아래를 검색합니다.
- "{국가} 긴급전화 경찰 구급차 화재"
- "주{국가} 대한민국 대사관 영사관 연락처"
- "{국가} 여행자 영사콜센터"

한국 외교부 영사콜센터(+82-2-3210-0404, 국가번호 없이 현지에서 무료 접속 가능한 경우도 있음)는 목적지와 무관하게 공통 정보로 항상 함께 안내합니다.

### 3단계: 상황별 대응 요령 정리

사용자 상황(또는 일반적으로 자주 발생하는 상황)에 맞춰 아래 카테고리로 정리합니다. 필요한 항목만 선택적으로 답변하세요.

1. **여권 분실/도난** — 현지 경찰서 신고(도난 증명서 발급) → 대사관/영사관 방문 → 여행증명서 발급 절차
2. **소매치기·도난** — 발생하기 쉬운 장소/수법(혼잡한 관광지, 대중교통 등), 즉시 취할 조치(카드 정지, 경찰 신고)
3. **질병·부상** — 여행자보험 가입 여부 확인, 현지 병원/약국 이용 방법, 응급실 이용 시 유의사항
4. **자연재해·치안 불안 지역** — 목적지에 해당 위험이 있는 경우 현재 상황과 외교부 여행경보 단계 확인 권고
5. **사기·바가지** — 그 여행지에서 흔히 보고되는 관광객 대상 사기 유형과 회피 방법

### 4단계: 예방 정보 제공 (사전 질문인 경우)

문제가 아직 발생하지 않은 경우, 검색 결과를 바탕으로 그 목적지에서 **자주 보고되는 사건·사고 유형 상위 2~3개**를 미리 알려주고, 각각의 예방 수칙을 함께 제시합니다.

### 5단계: 출처와 함께 안내, 최신성 강조

긴급 연락처나 여행경보 단계는 시점에 따라 바뀔 수 있으므로, 반드시 검색 출처를 함께 표기하고 "출발 전 외교부 해외안전여행(0404.go.kr) 또는 현지 대사관 공지로 최신 정보를 다시 확인하라"고 안내합니다.

## 사용 예시

**사용자 질문:** "필리핀 세부 여행 가는데 조심해야 할 게 있을까? 혼자 가."

**예상 동작:**
1. 목적지: 필리핀 세부, 사전 예방 정보 요청으로 판단
2. `web_search`로 "세부 여행자 안전 주의사항", "필리핀 긴급전화 대사관 연락처" 검색
3. 자주 보고되는 문제(택시 바가지, 관광지 소매치기, 야간 단독 이동 위험 등)와 예방법 정리
4. 긴급 연락처(현지 경찰/구급차, 주필리핀 한국대사관, 영사콜센터) 제공
5. "출발 전 외교부 해외안전여행 사이트에서 최신 여행경보 확인 권장" 안내

**사용자 질문:** "여권을 잃어버렸어, 지금 파리야"

**예상 동작:**
1. 이미 발생한 상황(사후 대처)으로 판단
2. 여권 분실 대응 절차를 단계별로 즉시 안내 (현지 경찰서 신고 → 주프랑스 대한민국 대사관 연락처와 위치 → 여행증명서 발급 절차)
3. `web_search`로 주프랑스 대한민국 대사관의 최신 연락처/주소 확인 후 제공

## 가이드라인

- 실제 응급 상황(사용자가 위급함을 표현하는 경우)에서는 정리에 시간 쓰지 말고 **가장 먼저 현지 긴급전화번호와 대사관 연락처부터 즉시 제시**하고, 이후에 상세 절차를 이어서 안내하세요.
- 특정 지역/집단에 대한 과도한 일반화나 편견이 담긴 표현은 피하고, 사실 기반의 안전 정보만 전달하세요.
