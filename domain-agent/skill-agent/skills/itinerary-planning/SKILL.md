# itinerary-planning

## 목적

목적지, 여행 기간(몇 박 며칠), 예산, 취향(휴양/액티비티/맛집 등) 정보를 바탕으로 **일자별 동선과 예상 예산**을 함께 제시합니다. 개인 여행자가 가장 먼저 요청하는 핵심 기능입니다.

## 반드시 따라야 할 프로세스

### 1단계: 필요한 정보 파악

다음 정보를 사용자 메시지에서 최대한 확인합니다. 일부가 빠져 있어도 **먼저 되묻지 말고** 2단계로 진행하세요 (빠진 정보는 3단계에서 추정으로 보완).
- 목적지(국가/도시)
- 여행 기간(몇 박 며칠)
- 예산 (없으면 추정 대상)
- 취향/스타일 (휴양, 액티비티, 맛집, 쇼핑, 가족 여행 등 — 없으면 "균형 잡힌 일반적인 일정"으로 가정)

### 2단계: 목적지 기본 정보 검색

`web_search`로 아래를 검색해 최신 정보를 확인합니다.
- "{목적지} 여행 코스 추천 {기간}일"
- "{목적지} 여행 경비 {기간}일 예산" (예산이 없을 때)
- "{목적지} 필수 관광지 명소"

### 3단계: 예산 추정 (사용자가 예산을 안 준 경우)

검색 결과를 바탕으로 아래 항목별 대략적인 1인 예산 범위를 추정합니다.
- 숙박 (1박 평균가 × 박수)
- 교통(현지 이동 + 필요시 항공/기차)
- 식비 (하루 평균 × 일수)
- 관광/액티비티

합산해서 "총 예상 경비: 약 OOO원 ~ OOO원 (1인 기준)" 형태로 제시하고, 이는 추정치이며 실제 항공권/숙소 가격은 별도 확인이 필요하다고 명시합니다.

### 4단계: 일자별 동선 작성

일차별로 아래 형식을 따라 작성합니다.

```
Day 1: [테마/지역]
- 오전: ...
- 오후: ...
- 저녁: ...
- 이동 참고: (지역 간 이동이 있다면 대략적인 소요시간)
```

동선을 짤 때는 지리적으로 가까운 장소를 같은 날에 묶고, 이동 시간이 긴 장소는 하루를 통째로 배정합니다.

### 5단계: 취향 반영 및 마무리

사용자가 밝힌 취향(휴양/액티비티 등)이 있으면 그에 맞춰 일정 비중을 조정합니다. 마지막에 "예산이나 특정 관심사(맛집/쇼핑/액티비티 등)를 알려주시면 더 맞춤 조정해드릴게요"처럼 후속 조정 여지를 안내합니다.

### 6단계: 여행지 주의사항 살짝 덧붙이기 (참고용)

목적지가 확정된 일정을 제시하는 경우, 답변 맨 끝에 **가볍게 참고용으로만** 그 여행지에서 흔히 발생하는 위험 요소를 1~2가지 짧게 덧붙입니다.

- `load_skill('emergency-info')`로 emergency-info 스킬을 불러오되, 그 스킬의 전체 절차(긴급 연락처 전체 조사, 대응 절차 등)를 다 수행하지는 마세요. "자주 보고되는 사건·사고 유형" 파악 부분만 가볍게 참고해서, 이 목적지에서 흔한 문제 유형 1~2가지와 짧은 예방 팁만 뽑아냅니다.
- 형식 예시: `"참고로 OOO 지역은 [소매치기/사기/야간 치안 등]가 종종 보고되니, [간단한 예방 팁] 정도만 유의하시면 좋아요 🙂"`
- 절대 하지 말 것: 긴급 연락처 전체 나열, 대사관 주소, 여권 분실 절차 등 emergency-info의 상세 대응 내용을 여기서 통째로 붙여넣지 마세요. 어디까지나 "가벼운 참고 문구" 한두 문장이어야 합니다.
- 더 자세한 안전 정보가 필요하면 emergency-info 스킬을 통해 별도로 물어보라고 짧게 안내해도 좋습니다.
- 목적지가 특정되지 않았거나(예: 여러 후보지를 비교 중) 이미 이번 대화에서 emergency-info로 같은 목적지에 대해 안내한 적이 있다면 이 단계는 생략합니다.

## 사용 예시

**사용자 질문:** "다낭 4박 5일 여행 계획 짜줘. 예산은 아직 모르겠어."

**예상 동작:**
1. 목적지: 다낭(베트남), 기간: 4박 5일, 예산: 미정, 취향: 미지정 → 균형 잡힌 일정으로 가정
2. `web_search`로 "다낭 여행 코스 추천 5일", "다낭 여행 경비 5일 예산" 검색
3. 예상 경비 산출 (숙박/교통/식비/액티비티 합산 범위 제시)
4. Day 1~5 일자별 동선 작성 (호이안 데이투어, 바나힐, 미케 비치 등 검색 결과 기반으로 배치)
5. "특정 취향(휴양 위주/액티비티 위주 등) 알려주시면 조정해드릴게요"로 마무리
6. 마지막 줄에 "참고로 다낭은 오토바이 대여 사고와 야시장 소매치기가 종종 보고되니, 귀중품은 가방 앞쪽에 보관하시는 게 좋아요 🙂" 정도로 짧게 덧붙임

## 가이드라인

- 예산 추정치는 반드시 "추정"임을 명시하고, 항공권/숙소의 정확한 가격은 별도 검색 도구나 실제 예약 사이트 확인이 필요하다고 안내하세요.
- 동선은 실제 지리적 이동 가능성을 고려하세요 (하루에 지리적으로 멀리 떨어진 장소를 여러 곳 넣지 않기).
- 정보가 최신이 아닐 수 있는 항목(요금, 운영시간 등)은 "최신 정보는 현지 확인 권장"이라고 짧게 덧붙이세요.
